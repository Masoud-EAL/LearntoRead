# ACSF coverage: key performance features and the games that show them

Every key ACSF performance feature (PF) below is quoted verbatim from the AMES/SEE
Reporting Checklist in the two Victorian course mapping documents:

- `22636VIC Course in Initial EAL Mapping` (08/09/2025)
- `22637VIC Course in EAL Mapping` (08/09/2025, updated by AMES April 2026)

These give the reduced list of **key** PFs, the ones the SEE Program treats as
demonstrable and assessable, which is exactly the set a game can be built against.
Nothing in the PF column is paraphrased or inferred: it is the source text, and it
is the same text the teacher panel prints as its evidence for each row.

**Every feature in this table is addressed by the app.** `.07` (speaking) is out of
scope: nothing here records or judges speech. Two features about handwriting and
legible script are also not claimed, because that is `tracing.html` and paper.

## Legend

| Mark | Meaning |
|---|---|
| ✅ had it | An existing game already demonstrated this |
| 🔧 extended | An existing game was extended to reach it |
| 🆕 built | A new game was built for it |
| 📊 from the run | Shown by how the learner works through a run, not by a right answer |

## Ceilings

The checklist tables for Numeracy (`.09` `.10` `.11`), Learning `.02` and Digital
(`.12` `.13`) stop at Pre Level 1 Stage B, so the app cannot award Level 1 for them
however well a learner does, and says so. Every Level 1 claim anywhere is marked
partial: one round of one game is not the sustained performance Level 1 describes.
